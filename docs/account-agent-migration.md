# 工作台账号 Agent 迁移

小红书、闲鱼、抖音、微博、B站、快手、京东、知乎八个工作台已接入实时 Multica Agent 目录。目录通过共用 Channel 服务端鉴权读取完整 Open API Agent list，包含未建立路由的 Agent；打开或刷新重新拉取，故障明确失败。监听和用途只能单选一个 Agent，服务端为当前账号、来源、用途创建或复用精确绑定，不更改原 Agent 的技能、指令或旧快照。配置保存、生成、批准与发送前再次检查账号及执行身份，换绑后已有回复需要重新分析。

私信、评论与内容任务的新记录保留 Agent 快照。历史归属来自记录自身保存的执行身份，不根据当前监听选择重标；没有可确认快照的小红书旧记录显示“历史未记录”。闲鱼可依据原路由确定的旧记录补充了历史身份。
